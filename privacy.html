Privacy Policy

Last updated: 22 October 2026

NoRoadBack Publisher uses YouTube API Services. By using this application you also agree to the YouTube Terms of Service and to Google’s Privacy Policy.

1. Who this policy applies to

NoRoadBack Publisher (“the application”) is a private, single-operator tool used exclusively by the owner of the YouTube channel @noroadback. The application does not accept sign-ups and has no end users other than the channel owner. This policy describes how the application handles data belonging to that single operator.

2. Data the application accesses

When the channel owner authorizes the application through Google OAuth 2.0, the application receives access to:

  • Metadata of the owner’s YouTube channel and videos (titles, descriptions, tags, status, thumbnails, captions, playlists, localizations).
  • Non-monetary YouTube Analytics for the owner’s own channel (views, watch time, retention).
  • The owner’s channel ID and basic Google account identifier returned by the OAuth flow.

The application does not request, access, store or transmit:

  • Any data belonging to Google accounts other than the channel owner’s.
  • Monetary / revenue analytics.
  • Private messages, email, Google Drive content, contacts or any other Google service outside YouTube.

3. OAuth scopes used and why

ScopeReason
https://www.googleapis.com/auth/youtubeCreate and manage playlists and video metadata on the owner’s channel.
https://www.googleapis.com/auth/youtube.uploadUpload video files to the owner’s channel.
https://www.googleapis.com/auth/youtube.readonlyRead current state of the owner’s channel/videos to plan publishing and avoid duplicates.
https://www.googleapis.com/auth/youtube.force-sslSet custom thumbnails and manage captions on the owner’s videos.
https://www.googleapis.com/auth/yt-analytics.readonlyRead non-monetary analytics for the owner’s own channel.

4. Where the data lives

The OAuth refresh token issued by Google is stored locally in a .env file on the channel owner’s own machine. Short-lived access tokens are held only in memory while the tool runs. Video files, titles, descriptions, captions and scheduling data are kept locally on the owner’s machine and in the owner’s own Google Workspace (Google Sheets / Google Drive) for internal planning. Neither tokens nor content are transmitted to any server operated by anyone other than Google (YouTube APIs).

5. How the data is used

  • To publish, update, localize and schedule the owner’s own videos on the owner’s own channel.
  • To read the owner’s own channel analytics to decide what to publish next.
  • Nothing is used for advertising. Nothing is sold or shared with third parties.
  • No automated profiling or decisions are made about any person other than evaluating the owner’s own publishing cadence.

6. Sharing with third parties

The application does not share any accessed data with any third party. The only external systems the application communicates with are Google’s YouTube Data API, YouTube Analytics API and (for upload content delivery) upload.youtube.googleapis.com. All transfers happen over HTTPS.

7. Retention and deletion

The refresh token is retained locally on the owner’s machine until the owner either deletes it from the .env file or revokes the application at myaccount.google.com/connections. Revocation makes the stored refresh token immediately unusable. On request to the contact address below, any local copies of the token, cached metadata or analytics snapshots will be destroyed.

8. Compliance with YouTube API Services

In accordance with the YouTube API Services Terms of Service and the YouTube API Services Developer Policies:

  • Data obtained through the YouTube API Services is used only to operate NoRoadBack Publisher for the owner’s own channel.
  • No YouTube API Services data is used for advertising, resold, or shared with third parties.
  • Users can revoke the application’s access to their YouTube data via the Google security settings page linked above.

9. Children

The application is not directed at children and has no end users other than the channel owner, who is an adult.

10. Changes to this policy

If this policy changes, the updated version will be published at this URL with an updated “Last updated” date.
